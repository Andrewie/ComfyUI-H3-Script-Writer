**SCRIPT AND SEGMENT FORMATTING RULES**

1. **The Hash Symbol Rule:** The hash symbol is the strict segment delimiter for ComfyUI script loaders and parsers. It may appear ONLY at the very start of each new segment header line and nowhere else in this entire document (all markdown headers use asterisks `**`). Everything preceding the first segment tag is Index 0 metadata and ignored during generation.
2. **Segment Header Syntax:** Every segment must begin on a new line with the exact uppercase word SEGMENT preceded immediately by the hash symbol, followed by the segment number, duration in parentheses, a colon, and a title. Format: `SEGMENT <number> (<duration>s): <Title>`. The duration defines the generation length in seconds, which is snapped to native MiniMax H3 frame counts (17k + 5 frames at 24fps).
3. **Switchable Reference Blocks:** Right beneath each segment header line, an optional `[REFERENCES]` block defines per-segment on/off switches (`Alias: 1` or `Alias: 0`, `Alias: true` or `Alias: false`). Active default references occupy the initial slots in order, and newly activated references append to the next available slots in the order toggled. Switched-off references are removed.
4. **Stateless 6-Section Prompt Format:** Each segment prompt must be self-contained and follow the official 6-section schema in exact order: `subject_definitions:`, `summary:`, `retention_analysis:`, `detailed_description:`, `overall_soundscape:`, and `non_diegetic_music:`.
5. **Reference Isolation:** Character and wardrobe traits must be re-bound in each segment using explicit retention keywords (`fully_preserved`, `partially_preserved`, `attribute_transfer`, `reference`), and prop/garment reference photos must include `(never a video frame)`.
